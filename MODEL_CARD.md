# Model Card: Прогноз вероятности дефолта (PD) ипотечных заемщиков

## 1. Назначение модели (Intended Use)
Модель предназначена для прогнозирования вероятности перехода кредита в состояние дефолта (просрочка 90+ дней) в следующем месяце. 
**Применение:** Расчет ожидаемых кредитных потерь (ECL) в рамках требований МСФО 9, а также для раннего выявления рискованных заемщиков (Early Warning System).

## 2. Данные (Data)
*   **Источник:** Публичные данные Freddie Mac Single-Family Loan-Level Dataset.
*   **Период:** 2009 – 2023 гг.
*   **Объем:** Более 43 млн записей (помесячная панель).
*   **Разбиение:** 
    *   Train: 2009–2015 (обучение)
    *   Calib: 2016–2017 (калибровка вероятностей)
    *   OOT (Out-of-Time): 2018–2023 (тестирование)
*   **Предобработка:** Замена сентинелов 999 на NaN, создание MNAR-флагов пропусков, винзоризация выбросов, создание поведенческих фичей (история просрочек за 12 мес.).

## 3. Архитектура (Model Architecture)
Модель использует **двухуровневый подход** в зависимости от текущего состояния кредита (State 0 = платит, State 1 = в просрочке).
*   **Алгоритмы:** Ансамбль из Логистической регрессии (30%) и градиентного бустинга CatBoost (70%).
*   **Балансировка:** Кластерный Undersampling (K-Means) с целевым соотношением 1:5 (1 дефолт на 5 нормальных кредитов).
*   **Калибровка:** Раздельный Platt Scaling для каждого состояния для получения честных вероятностей (PD), пригодных для МСФО 9.

## 4. Метрики качества (Metrics on OOT)
*   **Дискриминация:** Gini, ROC-AUC, PR-AUC, KS.
*   **Калибровка:** Brier Score, LogLoss, ECE (Expected Calibration Error).
*   **Стабильность:** PSI (Population Stability Index) < 0.1 (модель стабильна во времени).

## 5. Ограничения и Риски (Limitations)
*   **Макроэкономические шоки:** Модель обучена на исторических данных и может потребовать переобучения в случае беспрецедентных кризисов (например, пандемия COVID-19).
*   **Смещение выборки:** Данные Freddie Mac включают только ипотечные кредиты (super-conforming), модель может быть невалидна для потребительских кредитов или автокредитов.
*   **Интерпретируемость:** Для объяснения причин отказа конкретному клиенту рекомендуется использовать коэффициенты Логистической регрессии или SHAP-значения CatBoost.
