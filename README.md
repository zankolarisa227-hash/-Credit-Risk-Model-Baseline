# Freddie Mac 12-Month Probability of Default (PD)

Baseline-модель оценки вероятности дефолта ипотечных займов Freddie Mac.

## Задача

Для каждого ипотечного займа, выданного в 2018–2023 годах, оценить **вероятность дефолта в течение 12 месяцев** после точки наблюдения (месяц 12 жизни займа).  
Используются только данные, доступные до этой точки: origination-характеристики + агрегаты за первые 12 месяцев истории платежей.

### Ключевые параметры

| Параметр | Значение |
|----------|----------|
| Определение дефолта | `state == 2` (90+ дней просрочки или терминальное событие: short sale, REO, third-party sale) |
| Горизонт | 12 месяцев вперёд |
| Точка наблюдения | Месяц 12 жизни займа |
| Тип предсказания | Вероятность \( p \in [0, 1] \), а не класс |

Модель **не** предсказывает:
- дефолт когда-либо (lifetime PD);
- раннюю просрочку (30+ дней);
- досрочное погашение (prepayment).

## Данные

- Источник: Freddie Mac Single Family Loan-Level Dataset
- Когорта: займы, выданные в 2009–2021
- Объём: ~ займов (после фильтрации)
- Split по году выдачи:
  - Train: 2015–2019
  - Embargo:    2020
  - Calibration: 2021
  - OOT: 2022–2024
 
  - Stress:     2020

### 4. Обработка категориальных признаков

Категориальные признаки (штаты, цели кредита, тип владения) обрабатываются по-разному в зависимости от модели:

* **Для Логита:** Применяется One-Hot Encoding. Редкие категории (менее 1% наблюдений) объединяются в группу `OTHER` для борьбы с мультиколлинеарностью и разреженностью матрицы.  
* **Для CatBoost:** Используется нативное кодирование категорий (Ordered Target Encoding), что позволяет избежать взрыва размерности и переобучения.

---

### 4. Валидация и защита от переобучения

* **Time-based Split:**  
  Train (2015–2019) → Embargo (2020) → Calibration (2021) → OOT (2022–2024).
  
* **2020 год** полностью исключён из обучения и калибровки и используется как отдельный **stress-test** (проверка устойчивости модели в кризисный период).  
* **Embargo:** временной зазор между train и calibration для снижения утечки макроэкономических трендов.  
* **Масштабирование:** `StandardScaler` обучен только на Train и применён к остальным частям.


### 5. Борьба с дисбалансом классов (Undersampling)

Изначально доля проблемных переходов низкая.  
Для обучения применён **стратифицированный undersampling**:

* Из мажоритарного класса случайно сохраняется 70% наблюдений, чтобы сохранить достаточный объем данных .  
* Оставшиеся данные кластеризуются с помощью алгоритма K-Means (на основе ключевых финансовых признаков: credit_score, ltv, dti, loan_age) на K корзин.
* Из каждого кластера (бина) извлекается ограниченное количество наблюдений. Это гарантирует, что в обучающую выборку попадут все сегменты заемщиков (от надежных до пограничных), но без перекоса в сторону самого частого профиля.
* Все наблюдения из проблемного класса (y=1) сохраняются на 100%.
* Такой подход позволил сохранить репрезентативность выборки и повысить стабильность коэффициентов логистической регрессии.

## 6. Модели

**Алгоритм:**
-  Логистическая регрессия (LogisticRegression с L2-регуляризацией);
-  Градиентный бустинг (CatBoostClassifier) - для улавливания нелинейности
  
- **Калибровка:**
  Изотоническая регрессия или Platt Scaling на отдельном calib-периоде (2021). 
  Это необходимо, так как бустинг склонен к переоценке уверенности (overconfidence).
  
**Выход:**
`pd_score` ∈ [0, 1] - вероятность ухода в проблемное состояние (просрочка/дефолт) на следующем шаге.

**Threshold:**
для дефолта не подбирается (модель не принимает решение о выдаче кредита, а оценивает ожидаемые потери по уже выданному). Вместо этого качество оценивается через Brier Score и калибровочные кривые (ECE).
